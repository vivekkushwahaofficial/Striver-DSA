# Striver's DSA Sheet Solutions 🚀

A curated collection of Java solutions for problems from Striver's DSA (Data Structures & Algorithms) sheets, including NQT sheet and pattern printing exercises.

## 📂 Repository Structure

```text
Striver/
└── src/
    ├── nqt_sheet_problems_on_arrays/  # Array manipulation problems (Sum, Reversal, Search, etc.)
    ├── nqt_sheet_problems_on_numbers/ # Number theory problems (Primes, Palindromes, etc.)
    └── pattern/                       # Pattern printing exercises (Squares, Triangles, etc.)
```

## 🛠️ Topics & Problems Covered

### 1. Array Manipulations (`nqt_sheet_problems_on_arrays`)
- **Find Largest & Smallest Element**
- **Second Smallest & Second Largest**
- **Reverse an Array**
- **Sum & Average of Elements**
- **Rearrange Array in Increasing & Decreasing Order**
- **Count Frequency of Elements**
- **Block Swap Algorithm**

### 2. Number-based Problems (`nqt_sheet_problems_on_numbers`)
- **Palindrome Check** (single number & within range)
- **Prime Number Verification**

### 3. Pattern Printing (`pattern`)
- **Square Patterns**
- **Triangle Patterns**

## 🚀 How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/vivekkushwahaofficial/Striver-DSA.git
   ```
2. Navigate to the project directory and compile any Java file:
   ```bash
   javac src/nqt_sheet_problems_on_arrays/SmallestNumber.java
   ```
3. Run the compiled class:
   ```bash
   java -cp src nqt_sheet_problems_on_arrays.SmallestNumber
   ```
